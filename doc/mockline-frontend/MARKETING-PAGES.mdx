# Mockline — Marketing Pages Design Direction

> Design spec for: Privacy, Terms, About, Changelog, Roadmap.
> All pages live under `app/(marketing)/` and share the existing Nav + Footer.
> All pages use the established color system — no new colors introduced.
> Typography: headings use `var(--font-family-heading)` (Bricolage Grotesque), body uses `var(--font-family-sans)` (Inter).

---

## Shared Page Constraints

- Max content width: `720px` centered (prose pages) or `960px` (changelog, roadmap)
- Top padding: `80px` below nav, bottom padding: `80px` above footer
- No hero sections, no gradient text, no decorative illustrations
- Section dividers: `1px solid var(--color-border)` — never `<hr>` styled differently
- All external links open in `_blank` with `rel="noopener noreferrer"`
- Mobile: padding reduces to `24px` horizontal on screens below `640px`

### Initial entries to seed

**v0.1.0 — March 14, 2026** · Tags: `feature`
**Title:** Initial Release

> Mockline is now live. Upload an OpenAPI spec, provision a Docker-powered mock server, and get a live URL in seconds.

Bullets:
- Upload YAML or JSON OpenAPI 3.0 specifications
- Provision isolated Docker containers per spec version
- Automatic port assignment and public URL generation
- GitHub OAuth authentication via BetterAuth
- Free tier: 1 mock server, auto-stops after 1 hour

---

**v0.1.1 — March 15, 2026** · Tags: `performance`, `fix`
**Title:** Base Image Caching + Loopback Fix

> Two infrastructure fixes that make mock provisioning significantly faster and actually reachable.

Bullets:
- **Performance:** Introduced base image strategy — Contour CLI is now built once at API startup and cached. Provision time reduced from ~2 minutes to 5–10 seconds
- **Fix:** Patched Contour CLI binding from `127.0.0.1` to `0.0.0.0` at build time so mock containers are reachable from outside Docker
- **Fix:** Spec deletion now cascades — deleting a spec stops and removes all associated mock containers
